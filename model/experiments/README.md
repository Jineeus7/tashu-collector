## 채점 방식 (모든 실험 공통)

- **모델이 처음 보는 9일간(9/23~10/2, 추석 포함)** 을 3개 기간으로 나누고, 각 기간은 그 이전 데이터로만 학습
- 비교 기준: **지금 값 그대로** (기존 타슈 앱이 보여주는 지금 재고를 예측값으로 본 것)
- 표본: 10분마다 대여소 최대 400곳 무작위 → 2시간 뒤 537,200건
- 지표: 평균 오차(|예측 − 실제|의 평균), "2대 이상 있나" 적중률, 큰 변화 감지율
