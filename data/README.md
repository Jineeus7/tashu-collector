# 수집한 재고 데이터

타슈 오픈 API(대전교통공사)를 **10분마다** 호출한 응답을 그대로 gzip으로 저장했습니다.
과거 재고 기록이 공개돼 있지 않아 직접 모은 데이터입니다.

- 기간: **2026-08-31 ~ 2026-10-11** (42일), 발표 시연용으로 **2026-10-29 ~ 10-30** 추가
- 파일: `data/YYYY-MM-DD/YYYY-MM-DD_HH-MM-SS.json.gz` · 약 5,900개 · 하루 최대 144개
- 대여소: 약 1,373곳
- 빠진 구간: 9/9~9/10 일부 (GitHub 예약 실행 지연 → 9/10에 수집 방식을 바꿔 해결), 8/31은 낮부터 시작

## 파일 형식

```json
{
  "collected_at": "2026-09-15T00:00:08.208531+09:00",
  "data": {
    "results": [
      {"id": "ST0003", "name": "탄방동 한사랑병원", "x_pos": "36.348446", "y_pos": "127.390052",
       "address": "대전광역시 서구 탄방동 730", "parking_count": 0}
    ]
  }
}
```

- `parking_count`: 그 시각 대여소에 있는 자전거 수 (모델이 맞히는 값)
- `x_pos`, `y_pos`: 위도, 경도

## 읽기

```python
import sys; sys.path.insert(0, "tools"); import load   # 저장소 루트에서
rows = load.rows()        # [(수집시각, 대여소ID, 자전거 수), ...]
meta = load.stations()    # {대여소ID: {name, address, x_pos, ...}}
```

모델 학습에는 8/31~10/2의 **32일·4,476개**를 썼고, 9/23~10/2를 검증(채점)에 썼습니다.
